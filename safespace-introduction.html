SafeSpace exists for the moment right before someone decides whether to ask for help — the quiet, private, "I don't know what this is or if it's serious" moment. It's not a diagnosis tool. It's a soft landing.

A short screening gives language to what someone's feeling. From there, the app hands them something to actually do right now — breathe, ground, let a worry go, listen to something calm — plus a place to be heard anonymously, and a real hotline if it's more than the app can hold.

Screening and supportive guidance, never a medical diagnosis — said plainly, in the product's own words, in both languages.

01 · Assessment & AI analysis

A screening that explains itself, and never goes down

A short, PHQ-9-informed questionnaire opens the flow. The result isn't just a score — it's explained in plain language: concern level, likely reasons, and the patterns behind the answers.

  • An AI reads the answer pattern and suggests 2–4 next-step tools, each with its own short reason
  • If OpenAI is unavailable, the app quietly retries with Gemini
  • If both AI providers are down, a local rule-based recommender still returns something useful
  • Nobody using the app ever sees a raw error — just a result

02 · Daily mood check-in

A five-second honest snapshot

Five taps, no essay required. It's designed to lower the bar for checking in with yourself on an ordinary day, not just a bad one.

  • Five-point scale, one tap to log
  • No streaks, no "you missed a day" guilt — the team deliberately left streaks out
  • Lives right on the Home screen, next to the other quick tools

03 · Guided breathing

A real breathing exercise, in two languages

A paced inhale–hold–exhale cycle meant to nudge the nervous system down a notch. Fully bilingual, with the labels switching between Thai and English mid-exercise.

  • 4-second inhale, 4-second hold, 4-second exhale, on a loop
  • Thai and English labels, switchable live
  • Part of the same "Quick tools" set embedded in Home, Community, and Resources

04 · 5-4-3-2-1 grounding

The classic technique, stepped through slowly

A well-known grounding exercise for anxiety: work backward through your senses, one at a time, to pull attention back into the present room.

  • Five steps, one sense each, with its own icon and prompt
  • Available in Thai and English
  • Same "quick tool" embed pattern used across Home, Community, and Resources

05 · Worry release

Write it down, then watch it go

Type whatever's weighing on you, pick a release style, and it drifts off screen. It's built as a release, not a journal — the point is letting go of the sentence, not archiving it.

  • Three release effects: Sky Lantern, Breeze into Leaves, and Stardust
  • Custom animation per effect, tuned separately for light and dark mode
  • Available in Thai and English

06 · Ambient sound mixer

Six channels, built live in the browser — no audio files

A procedural ambient mixer using the Web Audio API: Rain, Ocean, Wind, Fireplace, a 432 Hz singing bowl, and Lo-Fi, each generated from filtered noise rather than a sound file.

  • Per-track and master volume, play/pause, and 15/30/60-minute sleep timers
  • Four one-tap presets: Deep Focus, Rainy Cabin, Zen, and Sleep
  • The player persists globally — it keeps playing while you browse Community or Resources

The AI fallback, sketched out

analyze-assessment.js
// A simplified sketch of the three-tier pattern — not the literal source.
async function analyzeAssessment(answers, lang) {
  try {
    return await callOpenAI(answers, lang);
  } catch (err) {
    logAIFailure('openai', err);
    try {
      return await callGemini(answers, lang);
    } catch (err2) {
      logAIFailure('gemini', err2);
      return localRuleBasedAnalysis(answers, lang); // never throws
    }
  }
}

Deployed as a Supabase Edge Function, kept behind a JWT so it can't be called anonymously.

How the noise channels above are made

ambient-channel.js
// Close to how Rain / Ocean / Wind actually run on this page —
// no audio files, just filtered white noise.
function makeNoiseChannel(ctx, { type, freq, q }) {
  const buffer = ctx.createBuffer(1, ctx.sampleRate * 2, ctx.sampleRate);
  const data = buffer.getChannelData(0);
  for (let i = 0; i < data.length; i++) data[i] = Math.random() * 2 - 1;

  const source = ctx.createBufferSource();
  source.buffer = buffer; source.loop = true;

  const filter = ctx.createBiquadFilter();
  filter.type = type; filter.frequency.value = freq; filter.Q.value = q;

  const gain = ctx.createGain();
  gain.gain.value = 0;

  source.connect(filter).connect(gain).connect(ctx.destination);
  source.start();
  return { gain, filter };
}

Rain uses a bandpass filter, Ocean a lowpass with a slow LFO on cutoff, Wind a bandpass with its own slower LFO.
